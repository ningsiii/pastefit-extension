# Tutorial image provenance

These assets are explicitly requested by the user for installation guidance.

- install.png: this Mac's Apple Installer introduction screenshot, orange Continue callout.
- security.png: this Mac's Privacy & Security main page, orange callouts for the sidebar and lower Security area. The user has already completed Gatekeeper approval; the screenshot therefore has NO Open Anyway button. The accompanying text must retain that distinction. No warning/control was fabricated.
- accessibility.png: this Mac's Device Control and Data Access screenshot, callouts for PasteFit and Add; unrelated app names/icons are covered.
- automation.png: this Mac's Automation settings, expanded PasteFit → Pages, callouts for disclosure and toggle.
- ready.png: the user-supplied cropped extension completion screenshot. Contains no account details; used only at the end of the separate complete tutorial, not recursively inside the live completion screen.

The first four images were annotated/redacted with image_gen using actual CUA screenshots as references; they are screenshot-based edited tutorial assets, not pixel-identical forensic originals. The labelled controls were visually compared with the observed system state. No attempt was made to reproduce a missing security warning or reset permissions to capture it. Raw system captures, user identity, unrelated application names, clipboard/document data are not committed. System versions/layouts differ.

The previous synthetic SVG diagrams have been removed. All PNGs are local assets, with no runtime fetch or network processing. Future replacements should retain this provenance distinction and avoid implying that screenshot annotations prove current permission status.
