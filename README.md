# 贴妥 PasteFit

<img src="public/icons/icon128.png" alt="贴妥" width="80" height="80">

**Fit to paste.** 把网页和 Markdown 内容，贴成清楚的文档或聊天文字。

## 怎么用

选中网页内容 → 右键 **贴妥智能复制** → 到 Word、WPS 或微信粘贴。

选区中的表格题注会保留在表格上方或下方，作为普通文字；不自动编号，也不创建Word题注字段。

需要修改内容或加序号、符号、Emoji：右键 **贴妥编辑**，修改后点“贴妥智能复制”，无需另选聊天或文稿方式。正文区域可滚动，工具与复制按钮固定；WPS与Pages入口在右上角“复制设置”。正文异常零宽/控制字符会触发标色检查：点击标记可切换清理或保留，最后点“复制”。正常特殊空格、单位与语言排版不单独弹窗；也可在编辑器主动“显示隐藏字符”。公式、代码和正常Emoji保持。

复制成功时，胶囊和编辑器的复制按钮原位显示对号与“已复制”，右键复制在原选区附近短暂提示。浏览器自己的普通“复制”不受贴妥接管。

## 能做什么

- 清理网页带来的字体、字色和背景底纹，保留标题、强调、列表、上下标与表格结构。
- 向文档提供富文本，向聊天软件提供有层次的纯文本；不需要为普通文字逐次选目标软件。
- 检查疑似多余的空格、零宽字符和占位残留，由你选择处理或保留。
- 本地编辑，插入序号、符号与 Emoji。
- 可选网页浮条：点击工具栏贴妥图标，进入“管理网站”，添加并授权网站，再开启浮条。默认关闭，刷新后生效；不开启也能右键使用。蓝色“复制”、橙色“编辑”的胶囊优先放在选区上方，避让网页按钮；普通正文和正反向选字都可使用。

## 公式：三种软件的区别

| 目标 | 操作与边界 |
| --- | --- |
| Word | 关闭 WPS 公式兼容，再智能复制、普通粘贴。已支持的公式可编辑；本机 Mac Word 常见分式、矩阵、下标已实测。 |
| WPS | 工具栏贴妥 → 公式设置 → 开启 WPS 公式兼容。整段粘贴保留公式源码；需将单条 LaTeX 粘到 WPS 公式框中转换。**不是整段自动生成原生公式。** |
| Pages（仅 Mac） | 关闭 WPS 兼容，在同一公式设置区打开独立 Pages 向导，安装并授权可选辅助程序。支持的公式和前三层标题可原生保留；四至六级标题可手动调整。 |

WPS 开关保存在本机，之后的智能复制沿用。**切回 Word 或 Pages 前请关闭。** 新打开的编辑器沿用保存值，编辑器内临时切换仅影响当前编辑器。

WPS 单条公式：在贴妥编辑器点中对应公式或源码 → “复制此公式” → WPS 插入公式框 → 粘贴并回车（部分版本需切换专业公式）。确认能编辑后，删除正文中对应的旧源码。只有 MathML、没有 LaTeX 的公式不能按此方式转换。

Mac 国内版 WPS 12.1.29182 已验证分式、矩阵、下标的源码转换与保存重开。Windows 新版流程尚未实机验证；不承诺所有软件版本及所有公式语法通用。Mac 辅助程序为单独安装项；普通文字复制和 WPS 路径无需安装它。Pages组件安装、授权、升级与源码构建见 [Mac辅助程序说明](native/macos/README.md)。Pages向导未提供可用下载时，不能据此认定原生公式已启用。

## 演示与测试

打开 [演示页面](tests/manual/demo/index.html)：固定16:9，左侧1–4段切换聊天排版、文档格式、隐藏字符、编辑材料，第5段展示Chrome商店官方图标、GitHub和完整地址，适合结尾介绍获取方式。页面没有模式切换或操作教程；需要复制时，手动选中材料并使用已安装贴妥的右键菜单。

## 安装与开发

普通使用请安装 [Chrome Web Store中的贴妥](https://chromewebstore.google.com/detail/idenmkpalcogianaoihjhhfoedefefcl)，商店是否提供 0.1.2 以条目显示为准；GitHub 源码更新不代表商店已更新。

本地加载：使用 Node.js 20+，在项目目录执行 `npm ci`、`npm run build`。打开 `chrome://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，选择构建出的 `dist/`。已有另一份贴妥时先停用其中一份，以免混用版本。

源码检查：`npm test -- --run`、`npm run typecheck`、`npm run lint`。打包需先构建；Windows 可执行 `npm run package`，ZIP 根目录应直接包含 `manifest.json`。普通构建不附带 Mac 辅助程序安装包。

发布源码和商店安装包分别更新，公开仓库Releases资产上架前，辅助程序下载地址不会可用。正式组件只连接商店扩展ID；开发自载版本请按Mac说明单独构建。

## 清理的边界

贴妥处理选区中可以取得的内容与复制格式，不判断是否由 AI 生成，不改写原意。不会还原已丢失的文字，也不修复目标文档中原有的排版、域或乱码。

已有注释编号、说明和参考文献文字会保留，但不创建 Word 页底脚注、文献数据库或自动交叉引用，不替作者补来源、改号或套用学校模板。普通空格点、换行箭头等“显示编辑标记”不属于应删除的正文。普通来源链接保留，文内跳转在剪贴板中可能降级为文字。图片不作为本版主要适配对象，可能降级为说明或链接。

## 隐私与许可

正文只在本地处理，不上传、不调用 AI，不保存聊天正文或剪贴板历史。保存的设置包括网站域名与开关、WPS 公式兼容偏好和 Pages 连接就绪状态。可选 Mac 辅助程序的临时文稿及权限见 [隐私说明](PRIVACY.md)。
